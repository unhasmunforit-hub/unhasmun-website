# 🌐 UNHAS Model United Nations (MUN) Website

Repository resmi untuk website Hasanuddin Model United Nations. Website ini berfungsi sebagai pusat informasi, publikasi berita/artikel, dan *landing page* utama organisasi.

![Tech Stack](https://skillicons.dev/icons?i=nextjs,react,tailwind,ts,sanity,vercel)

## 📋 Tentang Proyek

Website ini dibangun dengan arsitektur **Headless CMS** untuk performa tinggi dan kemudahan pengelolaan konten oleh tim non-teknis.

- **URL Produksi:** [https://unhasmun.org](https://unhasmun.org) 
- **Status:** 🟢 Active / Maintained

## 🛠️ Teknologi yang Digunakan

| Kategori | Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Frontend** | [Next.js 14](https://nextjs.org/) | App Router, Server Components |
| **Styling** | [Tailwind CSS](https://tailwindcss.com/) | Utility-first CSS framework |
| **CMS** | [Sanity.io](https://www.sanity.io/) | Manajemen konten (Artikel, Author, Kategori) |
| **Bahasa** | [TypeScript](https://www.typescriptlang.org/) | Static typing untuk keamanan kode |
| **Deployment** | [Vercel](https://vercel.com/) | Hosting frontend & serverless functions |
| **Analytics** | [Vercel Analytics](https://vercel.com/analytics) | Tracking pengunjung per halaman |
